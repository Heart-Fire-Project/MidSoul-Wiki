## 感谢您游玩午夜灵魂！

《午夜灵魂》是一张基于 Minecraft Java 1.21.11 打造的<span className="ms-ink" style={{'--fg':'#6525D0','--fg-d':'#A472FC'}}><strong>非对称竞技地图</strong></span>，你将作为<span className="ms-ink" style={{'--fg':'#245BDB','--fg-d':'#71A0FF'}}>灵魂</span>或<span className="ms-ink" style={{'--fg':'#D83931','--fg-d':'#FA7974'}}>灵魂守卫者</span>，在躲避或追逐中取得最终的胜利。

具体的玩法可以在游戏内通过进度中的“教程”标签页查阅，在第一次遇到相关机制时也会在聊天栏中进行相应的简短说明；同时，你也可以在[模式介绍](/midsoul/wiki/午夜灵魂/模式介绍)与[全局机制](/midsoul/wiki/午夜灵魂/全局机制)中查看更详细的信息！
