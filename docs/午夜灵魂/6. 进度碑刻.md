# 进度碑刻

## 教程

该页签简单描述了游戏内各机制与玩法，相关机制见[全局机制](/midsoul/wiki/午夜灵魂/全局机制)。

在触发教程时，会在聊天栏中显示一段简短文字供实时阅读，之后也可以在进度页面里阅读详细信息。

## 装饰品

该页签记录了玩家的[装饰品](/midsoul/wiki/午夜灵魂/饰品集册)解锁情况，同时，玩家也可以经由进度了解各装饰品的解锁方法。

部分经由隐藏进度解锁的装饰品不会直接写出解锁方式，在<span className="ms-ink" style={{'--fg':'#D83931','--fg-d':'#FA7974'}}>知晓剧透风险</span>后可以在“[未定义](/midsoul/wiki/午夜灵魂/进度碑刻#%E6%9C%AA%E5%AE%9A%E4%B9%89)”一栏进行浏览。

## 历程
