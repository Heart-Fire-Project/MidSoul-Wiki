# 进度碑刻

## 教程

该页签简单描述了游戏内各机制与玩法，相关机制见[全局机制](./6.%20%E5%85%A8%E5%B1%80%E6%9C%BA%E5%88%B6.md)。

在触发教程时，会在聊天栏中显示一段简短文字供实时阅读，之后也可以在进度页面里阅读详细信息。

## 装饰品

该页签记录了玩家的装饰品解锁情况，同时，玩家也可以经由进度了解各装饰品的解锁方法。

部分经由隐藏进度解锁的装饰品不会直接写出解锁方式，在<span className="ms-ink" style={{'--fg':'#D83931','--fg-d':'#FA7974'}}>知晓剧透风险</span>后可以在“未定义”一栏进行浏览。
